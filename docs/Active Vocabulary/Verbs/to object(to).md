# to object(to)

!!! info vocab "Перевод"
    1. возражать против (*object to*)
    2. выдвигать возражение, заявлять, что... (*object that*)
    3. оспаривать, выступать против (допущения, метода, вывода)

!!! tip vocab "Конструкции"
    - object to + существительное или -ing (to — предлог, не частица)
    - object that + предложение
    - raise an objection to + существительное

!!! example vocab "Пример"
    Several authors object to the classical Kirchhoff–Love plate theory when dealing with thick plates undergoing transverse shear deformation.
    { .sentence }

    Ряд авторов возражает против использования классической теории пластин Кирхгофа — Лява при рассмотрении толстых пластин, испытывающих поперечную сдвиговую деформацию.
    { .translation }
