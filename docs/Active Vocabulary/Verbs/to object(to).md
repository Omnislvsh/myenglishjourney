# to object(to)

**Перевод и академические значения:**
1. Возражать против, оспаривать (корректность гипотезы, упрощающего допущения или гипотезы плоских сечений).
2. Подвергать сомнению применимость (модели, линеаризации, метода к данному классу задач).
3. Выдвигать критические аргументы (против вывода или строгости доказательства).

**Конструкции:** object to + существительное или -ing (возражать против; здесь to — предлог, не частица); object that + предложение; не "object something"; objection (сущ.) — возражение

## Пример
Several authors object to the classical Kirchhoff–Love plate theory when dealing with thick plates undergoing transverse shear deformation.

**Перевод примера:** Ряд авторов возражает против использования классической теории пластин Кирхгофа — Лява при рассмотрении толстых пластин, испытывающих поперечную сдвиговую деформацию.
