# to validate

!!! info vocab "Перевод"
    1. подтверждать адекватность, валидировать (модель, метод)
    2. проверять достоверность, обосновывать (результат, гипотезу)
    3. признавать действительным, утверждать (формально)

!!! tip vocab "Конструкции"
    - validate a model / a hypothesis / a result
    - be validated by / against + данные, эксперимент
    - validate + существительное

!!! example vocab "Пример"
    We validate the proposed numerical model by comparing its output with data obtained from a laboratory experiment.
    { .sentence }

    Мы валидируем предложенную численную модель путем сравнения ее результатов с данными, полученными из лабораторного эксперимента.
    { .translation }
