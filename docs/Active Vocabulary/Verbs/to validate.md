# to validate

**Перевод и академические значения:**
1. Валидировать, подтверждать адекватность модели (сравнением с экспериментом).
2. Подтверждать границы применимости (формулы, закона).
3. Проверять физическую состоятельность расчета.

**Конструкции:** validate + существительное (a model / a hypothesis / a result); be validated by + чем; validation (сущ.) — валидация, подтверждение; valid / validity — действительный / обоснованность; invalidate — признавать недействительным

## Пример
We validate the proposed numerical model by comparing its output with data obtained from a laboratory experiment.

**Перевод примера:** Мы валидируем предложенную численную модель путем сравнения ее результатов с данными, полученными из лабораторного эксперимента.
