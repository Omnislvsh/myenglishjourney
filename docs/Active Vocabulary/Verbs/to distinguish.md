# to distinguish

!!! info vocab "Перевод"
    1. различать (*distinguish between A and B*)
    2. отличать одно от другого (*distinguish A from B*)
    3. выделять особый элемент, признак (*distinguished point* — выделенная точка)

!!! tip vocab "Конструкции"
    - distinguish between A and B
    - distinguish A from B
    - be distinguished by + признак — выделяться, характеризоваться

!!! example vocab "Пример"
    It is important to distinguish between convergence in probability and almost sure convergence.
    { .sentence }

    Важно различать сходимость по вероятности и сходимость почти наверное.
    { .translation }
