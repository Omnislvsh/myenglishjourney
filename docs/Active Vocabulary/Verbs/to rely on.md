# to rely on

!!! info vocab "Перевод"
    1. опираться на, основываться на (теорему, принцип, метод)
    2. полагаться на, рассчитывать на
    3. зависеть от, исходить из (допущения, условия)

!!! tip vocab "Конструкции"
    - rely on + существительное
    - rely on somebody to + глагол
    - rely heavily on + существительное — в значительной мере опираться на

!!! example vocab "Пример"
    The classical theory of elasticity relies on the assumption that the material is homogeneous and isotropic.
    { .sentence }

    Классическая теория упругости опирается на предположение о том, что материал является однородным и изотропным.
    { .translation }
