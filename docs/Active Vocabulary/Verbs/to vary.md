# to vary

!!! info vocab "Перевод"
    1. изменяться, меняться (о величине: *vary with*)
    2. различаться, колебаться в пределах (*vary from A to B*)
    3. варьировать, изменять (параметр; в вариационном исчислении — функционал)

!!! tip vocab "Конструкции"
    - vary from A to B
    - vary with / according to / depending on + что-то
    - vary + существительное — варьировать (*vary a parameter*)

!!! example vocab "Пример"
    The modulus of elasticity varies along the length of the rod depending on the local temperature distribution.
    { .sentence }

    Модуль упругости изменяется по длине стержня в зависимости от локального распределения температуры.
    { .translation }
