# to sense

!!! info vocab "Перевод"
    1. чувствовать, ощущать (интуитивно, без доказательств)
    2. считывать, регистрировать (сигнал, величину датчиком)
    3. определять (направление, знак, ориентацию)

    Существительное: sense — направление обхода (в математике), смысл, ощущение.

!!! tip vocab "Конструкции"
    - sense that + предложение
    - sense + существительное (*sense a change / a signal*)
    - sense what / how / who + придаточное

!!! example vocab "Пример"
    A small sensor is attached to the beam to sense changes in vibration during the cyclic test.
    { .sentence }

    К балке прикреплен небольшой датчик для считывания изменений вибрации во время циклического испытания.
    { .translation }
