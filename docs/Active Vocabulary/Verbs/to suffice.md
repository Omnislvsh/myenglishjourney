# to suffice

!!! info vocab "Перевод"
    1. быть достаточным (*a condition suffices*)
    2. хватать для чего-либо (*suffice for + существительное*)
    3. в доказательствах: достаточно (*it suffices to show that...*)

!!! tip vocab "Конструкции"
    - it suffices to + глагол
    - suffice for + существительное
    - suffice it to say (that) — достаточно сказать

!!! example vocab "Пример"
    To check the stability of the numerical scheme, it suffices to test it on a simple one-dimensional problem.
    { .sentence }

    Чтобы проверить устойчивость численной схемы, достаточно протестировать ее на простой одномерной задаче.
    { .translation }
